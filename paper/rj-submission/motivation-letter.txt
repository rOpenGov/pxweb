Dear Editors,

We are pleased to submit “Opening Up Official Statistics in R with pxweb” as a contributed research article for The R Journal.

Official statistics are used across disciplines, but retrieving them through PxWeb requires users to interpret table metadata, work within provider limits, and record which data they retrieved. The manuscript presents pxweb, a general R client for both PxWeb API versions. It compares pxweb with related software and explains how its common interface validates selections against provider metadata, splits large requests into smaller ones, and preserves notes and citation information.

The paper complements the package vignette by explaining the design of the batching algorithm and showing how provider configuration, query validation, and response handling work together. A case study uses a 967,176-cell population query from Statistics Sweden to demonstrate the workflow from table discovery to analysis and visualization. The manuscript describes pxweb 1.0.0, which we plan to release alongside the article. We verified that the accompanying scripts reproduce the results and figures with the CRAN release, pxweb 0.19.2, using the bundled data snapshots without contacting a live API.

pxweb has been available on CRAN since 2014 and has been used in published research across several fields, as documented in the manuscript. The package includes a workflow vignette and automated tests that check returned values. User reports also guide testing: when a user reported that large downloads from Statistics Finland hit the API's rate limit (https://github.com/rOpenGov/pxweb/issues/281), we added a live regression test for a large query against that API. We expect the paper to interest R users who work with official statistics, as well as users of public statistical databases.

The manuscript has not been published previously and is not under consideration elsewhere. All authors have approved the submission.

Thank you for considering our manuscript.

With kind regards,

Måns Magnusson, corresponding author
