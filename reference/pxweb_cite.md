# Cite a PXWEB data object

Cite a PXWEB data object

## Usage

``` r
pxweb_cite(x, style = "citation")
```

## Arguments

- x:

  a `pxweb_data` or `pxweb_data_v2` object to cite.

- style:

  see [`bibentry`](https://rdrr.io/r/utils/bibentry.html).

## Details

Functionality to automatic cite PXWEB data objects.
