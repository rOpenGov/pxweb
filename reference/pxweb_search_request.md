# Do a PXWEB search GET request

Do a PXWEB search GET request

## Usage

``` r
pxweb_search_request(url, query, ...)
```

## Arguments

- url:

  a PXWEB search URL.

- query:

  a named list of query string parameters.

- ...:

  further arguments passed to
  [`httr::GET`](https://httr.r-lib.org/reference/GET.html).
