# Construct a PXWEB API v2 query selection helper.

Construct a PXWEB API v2 query selection helper.

## Usage

``` r
pxweb_query_selection(
  type,
  value_codes,
  codelist = NULL,
  output_values = NULL,
  class = character()
)
```

## Arguments

- type:

  selection type.

- value_codes:

  values to use in the v2 `valueCodes` selection.

- codelist:

  optional codelist id.

- output_values:

  optional output values mode.

- class:

  additional S3 class names.
