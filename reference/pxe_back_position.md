# Move in the `pxweb_explorer` position

Move in the `pxweb_explorer` position

## Usage

``` r
pxe_back_position(pxe)

pxe_add_position(pxe, new_pos)
```

## Arguments

- pxe:

  a `pxweb_explorer` object.

- new_pos:

  add a new position.

## Details

`pxe_back_position` moves back one position and `pxe_add_position` moves
forward, based on user choice.
