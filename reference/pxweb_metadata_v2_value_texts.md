# Get value texts from a PXWEB API v2 dimension.

Get value texts from a PXWEB API v2 dimension.

## Usage

``` r
pxweb_metadata_v2_value_texts(dim, values)
```

## Arguments

- dim:

  a dimension list from a PXWEB API v2 metadata response.

- values:

  a character vector of value codes.

## Value

a character vector of value labels aligned with `values`.
