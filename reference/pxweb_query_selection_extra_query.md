# Build codelist-related query parameters for a v2 selection helper.

Build codelist-related query parameters for a v2 selection helper.

## Usage

``` r
pxweb_query_selection_extra_query(x, variable_code)
```

## Arguments

- x:

  a `pxweb_query_selection` object.

- variable_code:

  PXWEB variable code.
