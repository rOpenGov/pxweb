# Clear cache of all (or one) `pxweb` object

Clear cache of all (or one) `pxweb` object

## Usage

``` r
pxweb_clear_cache(x = NULL)
```

## Arguments

- x:

  a `pxweb` object to clear cache for. Default is NULL (clear
  everything).

## Details

Clean the cache and sleep to restore api timing limit.
