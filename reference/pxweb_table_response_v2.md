# Construct a `table_response_v2` object.

An object that contain the data for a given PXWEB TableResponse (API
v2).

## Usage

``` r
pxweb_table_response_v2(x)
```

## Arguments

- x:

  a list returned from a PXWEB API to convert to a `table_response_v2`
  object.

## Value

a `pxweb_table_response_v2` object.
