# Convert one query value to a PXWEB API v2 selection fragment.

Convert one query value to a PXWEB API v2 selection fragment.

## Usage

``` r
pxweb_query_value_as_v2(x, variable_code)
```

## Arguments

- x:

  a character vector or `pxweb_query_selection` object.

- variable_code:

  PXWEB variable code.
