# Get ordered values from a PXWEB API v2 dimension.

Get ordered values from a PXWEB API v2 dimension.

## Usage

``` r
pxweb_metadata_v2_values(dim)
```

## Arguments

- dim:

  a dimension list from a PXWEB API v2 metadata response.

## Value

a character vector of value codes ordered by the dimension index.
