# Construct a `pxweb_data_jsonstat2` object.

An object that contains JSON-stat2 data returned by a PXWEB API v2
`/tables/{tableId}/data` endpoint.

## Usage

``` r
pxweb_data_jsonstat2(x)
```

## Arguments

- x:

  a list returned from a PXWEB API v2 data endpoint.

## Value

a `pxweb_data_jsonstat2` object.
