# Build a PXWEB API v1 table URL from a search hit

Build a PXWEB API v1 table URL from a search hit

## Usage

``` r
pxweb_search_v1_table_url(api_url, path, id)
```

## Arguments

- api_url:

  the PXWEB API v1 database root URL.

- path:

  the search hit path.

- id:

  the search hit table id.
